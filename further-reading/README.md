# Further explorations / הרחבות ללימוד עצמי

Three complete optional self-study chapters, in English and Hebrew, that expand
the brief "Going further" invitations attached to Weeks 1–3: Lissajous curves,
total internal reflection and fibers, and random walks and diffusion.

This material is **unexamined, not a prerequisite, and separate from the graded
bonus**. The new physics and mathematics are taught here.

## Read the companion

Each chapter is a Jupyter notebook with the full narrative, equations, physical
assumptions, runnable examples, and saved outputs. An English print volume is
also provided.

- **Lissajous curves:** [English](notebooks/week01-lissajous-en.ipynb) · [עברית](notebooks/week01-lissajous-he.ipynb)
- **Total internal reflection:** [English](notebooks/week02-total-internal-reflection-en.ipynb) · [עברית](notebooks/week02-total-internal-reflection-he.ipynb)
- **Diffusion and random walks:** [English](notebooks/week03-diffusion-en.ipynb) · [עברית](notebooks/week03-diffusion-he.ipynb)
- **English print volume:** [PDF](further_material.pdf)
- **Worked answers (self-check):** [English](solutions-en.md) · [עברית](solutions-he.md)

## Run a chapter

Open a notebook and select the **Julia 1.12** kernel (see the repository
`STUDENT_SETUP.md`). The first cell activates the course environment. Read the
physical question, predict an outcome, and run the cells in order; use **Restart
Kernel and Run All** before changing parameters. The worked answers are for
self-checking — attempt the investigations first.
