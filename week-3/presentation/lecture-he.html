כאשר חישוב אחד הופך לרבים, נחזור במכוון, נשמור היסטוריות מסודרות בווקטורים ונצעיד מודל קדימה בזמן.

עדכון אוילר: לגזור את השורות שאנו חוזרים עליהן

עבור מרווח קטן Δt: rₙ₊₁ = rₙ + vₙ Δt, ואז vₙ₊₁ = vₙ + aₙ Δt עם מצב וקטורי r=(x,y), v=(vx,vy), a=(0,−g).

ללא גרר, כבידה אחידה, +x אופקי ו-+y מעלה. המקום משתמש במהירות הישנה; זו מוסכמת אוילר המפורסמת.

סימולציה ראשונה

g = 9.81        # m/s^2
speed = 20.0    # m/s
angle = pi / 4
r = [0.0, 0.0]   # m
v = [speed * cos(angle), speed * sin(angle)]   # m/s
a = [0.0, -g]    # m/s^2
dt = 0.1         # s
T = 2.0          # s
N = round(Int, T / dt)
trajectory_x = [r[1]]
trajectory_y = [r[2]]
velocities_x = [v[1]]
velocities_y = [v[2]]
for step in 1:N
    r = r + v * dt
    v = v + a * dt
    push!(trajectory_x, r[1])
    push!(trajectory_y, r[2])
    push!(velocities_x, v[1])
    push!(velocities_y, v[2])
end
println("Euler final position: ", round(r[1]; digits=4), ", ", round(r[2]; digits=4))
Euler final position: 28.2843, 9.6453

זמן סופי קבוע T לפני נחיתה, כך שכל הרצה שאנו משווים מסתיימת באותו זמן. הווקטורים שומרים את רכיבי המקום והמהירות בכל צעד.

שרטוט דגימות מול הנתיב המדויק

using Plots
r0 = [0.0, 0.0]
v0 = [speed * cos(angle), speed * sin(angle)]
exact_trajectory_x = Float64[]
exact_trajectory_y = Float64[]
for t in 0:dt:T
    push!(exact_trajectory_x, r0[1] + v0[1] * t + 0.5 * a[1] * t^2)
    push!(exact_trajectory_y, r0[2] + v0[2] * t + 0.5 * a[2] * t^2)
end
p = plot(title="Projectile Motion: Euler vs Exact",
         xlabel="x (m)", ylabel="y (m)", frame=:box)
p = plot!(p, trajectory_x, trajectory_y, label="Euler", lw=2)
p = scatter!(p, trajectory_x, trajectory_y, label=:none, lw=2)
p = plot!(p, exact_trajectory_x, exact_trajectory_y, label="Exact", lw=2, ls=:dash)
display(p)

הנקודות הן דגימות אוילר השמורות; העקומה המקווקוית היא הפרבולה המדויקת. ב-t=T הדגימה נמצאת מעל הנקודה המדויקת ב-g·T·dt/2 = 0.981 מ.

אוילר והפתרון המדויק: הפלט הגרפי

עידון והשוואה לתשובה המדויקת

using LinearAlgebra
g = 9.81; speed = 20.0; angle = pi / 4; T = 2.0
r0 = [0.0, 0.0]
v0 = [speed * cos(angle), speed * sin(angle)]
a = [0.0, -g]
for dt in (0.2, 0.1, 0.05, 0.02)
    r = copy(r0); v = copy(v0)
    N = round(Int, T / dt)
    for step in 1:N
        r = r + v * dt
        v = v + a * dt
    end
    exact = r0 + v0 * T + 0.5 * a * T^2
    println("dt = $dt, error = ", round(norm(r - exact); digits=4), " m")
end
dt = 0.2, error = 1.962 m
dt = 0.1, error = 0.981 m
dt = 0.05, error = 0.4905 m
dt = 0.02, error = 0.1962 m

הקטנת dt בחצי מחצית את השגיאה: התכנסות מסדר ראשון, עם r_N − r_exact(T) = −½a·T·Δt. בדקו קטן פי עשר לפני ההסבר.

המשך: סכמות מסדר גבוה יותר

אוילר משמיט ½a(Δt)² בכל צעד. קחו חצי צעד, העריכו את הנגזרת שם, ואז קחו את הצעד המלא: שיטה מסדר שני (מדויקת כאן בתאוצה קבועה). דגימות נוספות במקומות חכמים נותנות RK4. רקע אופציונלי — לא נדרש בקורס זה.

בדיקות מבחינות בין גבולות מספריים לפיסיקליים

היסטוריה מיושרת

כל הווקטורים גדלים באיבר אחד לכל צעד ומתחילים במצב ההתחלתי.

עצירה

ציינו איזה כלל עצר: חציית קרקע או סוף חלון הסימולציה.

עידון

הקטינו את dt בחצי והשוו. זה בודק שגיאת צעד זמן, לא פיסיקה מושמטת.

המשך לעבודה

תרגול

חיפוש חסום עם while לדגימת קירור ראשונה על הסף או מתחתיו; שוויון נחשב.

תרגיל בית

זריקת פטיש עם גרר ריבועי: קריאת חמישה קלטים, לולאה עד הדגימה הראשונה מתחת לקרקע או עד T, הדפסת מרחק ושמירת איור המסלול.

בונוס והמשך

בונוס אופציונלי: השוואת אוילר קדמי, אוילר-קרומר ו-velocity Verlet לפי אנרגיה סופית. המשך חקר: הליכות אקראיות ודיפוזיה — מסלול אחד אינו סטטיסטיקת אנסמבל.
