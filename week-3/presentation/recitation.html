Quick recap

  • for: known values; while: stop when a condition is false.
  • Every while loop needs initialization, condition, update, and a termination argument.
  • Vectors use 1-based indexing; use end, length, eachindex, and push!.

Sampled cooling

At each minute, Tₖ₊₁ = 0.9Tₖ. We seek the first sample that reaches 81 °C; equality counts. This is a discrete model, not a derivation of Newton cooling.

let temperature = 100.0   # C
threshold = 81.0          # C
minute = 0
while temperature > threshold
    temperature = 0.9 * temperature
    minute = minute + 1
end
println((minute, temperature))
end

Output: (2, 81.0).
