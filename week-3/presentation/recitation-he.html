קירור עד לסף

נעקוב אחר תנאי, עדכון ונקודת עצירה.

מחברת התרגול המלאה

תזכורת

לולאת for עוברת על ערכים ידועים; לולאת while נעצרת כשהתנאי שקר. בכל לולאה נזהה אתחול, תנאי, עדכון ונימוק עצירה.

קירור נדגם

בכל דקה Tₖ₊₁ = 0.9Tₖ. נחפש את הדגימה הראשונה שמגיעה ל-81°C; שוויון נחשב להגעה לסף.

let temperature = 100.0   # C
threshold = 81.0          # C
minute = 0
while temperature > threshold
    temperature = 0.9 * temperature
    minute = minute + 1
end
println((minute, temperature))
end
(2, 81.0)

הפלט הוא (2, 81.0). ללא עדכון הטמפרטורה, הלולאה אינה נעצרת.

מעקב והעברה

בדגימה 0: 100; בדגימה 1: 90; בדגימה 2: 81. התנאי המחמיר temperature > threshold עוצר בדיוק בשוויון.

בעבודה הנתמכת נתחיל את מסלול המרפסת: נשמור t, x, y, vx, vy, נבדוק אורכים שווים ודגימת נחיתה ראשונה, ונשווה dt ל-dt/2.
