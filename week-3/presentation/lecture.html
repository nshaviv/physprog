When one calculation becomes many, we repeat deliberately, store aligned histories, and check what the timestep changed.

Why loop?

A physical trajectory

A computer does not see a continuous curve. It updates and stores samples at many times until a stated stopping event.

A repeatable pattern

Loops replace copied calculations. They make the update rule, the counter, and the stopping condition inspectable.

Vectors preserve order—and Julia starts at 1

height = [1.0, 1.5, 2.0, 2.5]   # m
println(length(height))
println(height[1], ", ", height[end])
println(height[2:3])
4
1.0, 2.5
[1.5, 2.0]

end is the last index; a slice copies a selected part. Julia's ordinary vectors start at index 1.

Indices, slices, and building a vector

part = height[2:3]
part[1] = 99.0
println(height)
for i in eachindex(height)
    println("sample $i: $(height[i]) m")
end

part = height[2:3] copies those entries, so changing part[1] leaves height unchanged. eachindex supplies valid indices.

squares = Int[]
for n in 1:4
    push!(squares, n^2)
end
println(squares)

Int[] starts an empty vector. push! mutates it; the exclamation mark marks a mutating operation.

Slices and measurement summaries

Statistics is supplied with Julia, so it needs no package installation. Corrected sample standard deviation uses n−1; a trajectory is not automatically a set of independent repeated measurements.

Euler update: derive the two lines we repeat

For a small interval Δt: xₙ₊₁ = xₙ + vₓ,ₙ Δt, yₙ₊₁ = yₙ + vᵧ,ₙ Δt.

No drag, uniform gravity, +x horizontal and +y upward: vₓ,ₙ₊₁=vₓ,ₙ, vᵧ,ₙ₊₁=vᵧ,ₙ−gΔt.

We use the old velocity for the position update, then update velocity. This is the published Euler convention for this lesson.

Store the complete sampled trajectory

using Plots
g = 9.81        # m/s^2
dt = 0.05       # s
t = [0.0]       # s
x = [0.0]       # m
y = [1.0]       # m
vx = [10.0 * cosd(45.0)]   # m/s
vy = [10.0 * sind(45.0)]   # m/s
while y[end] > 0.0
    push!(t, t[end] + dt)
    push!(x, x[end] + vx[end] * dt)
    push!(y, y[end] + vy[end] * dt)
    push!(vx, vx[end])
    push!(vy, vy[end] - g * dt)
end
trajectory = plot(x, y; xlabel="x (m)", ylabel="y (m)",
                  label="Euler samples")
display(trajectory)
println("samples = $(length(t)); landed = $(y[end] <= 0)")
samples = 34; landed = true

All vectors include the initial state and the first nonpositive-height sample. We do not replace the final negative height with zero.

Checks distinguish numerical from physical limits

Aligned history

All five vectors have equal length and start at t=0.

Stopping convention

The last point is the first sampled y≤0; it is not the exact impact point.

Refinement

Halve dt and compare. It addresses timestep error, not omitted drag or impact physics.

Handoff

Recitation

Use a bounded while search for the first cooling sample at or below a threshold; equality counts.

Core HW
