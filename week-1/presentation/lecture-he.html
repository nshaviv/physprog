השאלה: האם המוליך אוהמי כאן?

מודל

V = RI. שיפוע מתח (V) מול זרם (A) הוא V/A = Ω, כלומר התנגדות.

תחום ובדיקה

מניחים מוליך אוהמי במצב קבוע בקירוב ובשדה חלש. ב־I=0 החוק האידיאלי נותן V=0; חימום ומגעים עלולים לשבור את המודל.

תצפיות אינן המודל המותאם

נריץ מתכון נתון; הזרם והמתח נשמרו ב־current וב־voltage. שליטה עצמאית בווקטורים ובהתאמה תגיע בהמשך.

n = length(current)
I_bar = sum(current) / n   # A
V_bar = sum(voltage) / n   # V
dI = current .- I_bar      # A
dV = voltage .- V_bar      # V
resistance = sum(dI .* dV) / sum(dI .^ 2)   # ohm
offset = V_bar - resistance * I_bar   # V

נקרא פלט ונבדוק את שני האיורים

residual = measured − predicted; תבנית שיטתית מערערת את המודל.

שגיאות הן מידע

תחביר

resistance = אינו שלם.

זמן ריצה

resistence הוא שם שלא הוגדר.

לוגית/מדעית

current / voltage רץ, אך A/V היא מוליכות ולא התנגדות.

רקע מתמטי לבחירה: גזירת ההתאמה

גזירת התאמת ריבועים פחותים

נמזער S(R,b) = Σ[Vᵢ − (RIᵢ+b)]². איפוס הנגזרת לפי b נותן b = V̄ − RĪ: הישר עובר בנקודת הממוצעים.

איפוס הנגזרת לפי R והצבת b נותנים Σ(Iᵢ−Ī)(Vᵢ−V̄) = R Σ(Iᵢ−Ī)². חלוקה נותנת את נוסחת השיפוע.

אם כל הזרמים שווים אין שיפוע יחיד. הגזירה המלאה נמצאת בתיבה בפרק 1; זהו רקע לבחירה, ולא הבונוס המזכה בשליש נקודה.
