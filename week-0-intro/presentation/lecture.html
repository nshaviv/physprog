At CERN: tracing a Higgs candidate in CMS

Two energetic photons leave reconstructed signals in the detector. Their energies and directions give physicists the pair's invariant mass.

The mass relation comes from four-momentum conservation; numerical reconstruction extracts photon properties from detector signals. Across many collisions, the mass distribution showed an excess near the Higgs-boson mass.

Julia notation follows the model

y = C * x

Here x, u, and y are vectors, while A, B, and C are matrices. We can compare each line of code directly with the corresponding equation.

Install Julia carefully before the first lab

1 · Get the official release

Download Julia 1.12.6 for your operating system from julialang.org/downloads. Install it normally; do not use a random copy from a search result.

2 · Start the REPL

Open Julia and run VERSION. It should report v"1.12.6". The REPL evaluates one Julia expression at a time.

3 · Install VS Code + extension

Install VS Code from its official site, then the Julia extension. Choose the Julia executable if the extension cannot find it.

4 · Verify the whole path

In a Julia file, run println(2 + 3). Save, run, and locate both the displayed result and terminal output. Ask for help with the exact error text and your operating system.

Public gravitational-wave data: two sites

from gwosc.datasets import event_gps
from gwpy.timeseries import TimeSeries
from gwpy.signal import filter_design
t0 = event_gps("GW150914")
h = TimeSeries.fetch_open_data("H1", t0-16, t0+16)
l = TimeSeries.fetch_open_data("L1", t0-16, t0+16)
bp = filter_design.bandpass(50, 250, h.sample_rate)
ns = [filter_design.notch(f, h.sample_rate)
      for f in (60, 120, 180)]
zpk = filter_design.concatenate_zpks(bp, *ns)
hf = h.filter(zpk, filtfilt=True)
lf = l.filter(zpk, filtfilt=True)
lf.shift("6.9ms"); lf *= -1
