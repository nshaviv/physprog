טיזר: תצפיות הופכות לבדיקת מסלול

דקלינציות היסטוריות אינן עדיין קואורדינטות מסלול. עם תכנות, גאומטריה והתאמה נוכל להשוות מודל מעגלי למודל אליפטי מול המדידות הללו.

זו דרכו של הסמסטר הראשון: לקרוא נתונים, למדל אותם, לבחון אותם ולדווח מה הנתונים כן ומה אינם יכולים לבסס.

Julia ו-Python הן כלים משלימים

Julia

סימון מתמטי קריא, עבודה אינטראקטיבית וספריות נומריות יעילות תומכים בליבת הקורס.

Python

מערכת אקולוגית מדעית רחבה הופכת אותה לשפה חשובה להעברה. מודלים, בדיקות והרגלי נתונים עוברים בין שפות.

מהמודל המתמטי לקוד

המשוואות שאנחנו רושמים, xn+1 = A xn + B un ו-yn = C xn, מתורגמות כמעט שורה-מול-שורה לקוד:

x_next = A * x + B * u
y = C * x

כאן x, u ו-y הם וקטורים, ו-A, B ו-C מטריצות. אותו הרגל תרגום חל גם על ביטויים שנפגוש לאורך הסמסטר:

Σ xi → sum(x)

√x → sqrt(x)

x² → x^2, ו-xi² על מערך → x.^2

A·x → A * x

xi·yi בסכום → sum(x .* y)

d f/d x או ∇f → gradient(f, x)

ל-Python יש מערכת אקולוגית לכל דבר

המערכת האקולוגית הרחבה של Python הופכת מגוון עצום של משימות לשורות ספורות — מניקוי נתונים ועד לארכיונים מדעיים ציבוריים. כאן נשלוף נתוני גלי כבידה אמיתיים משני גלאים:

from gwosc.datasets import event_gps
from gwpy.timeseries import TimeSeries
from gwpy.signal import filter_design
t0 = event_gps("GW150914")
h = TimeSeries.fetch_open_data("H1", t0-16, t0+16)
l = TimeSeries.fetch_open_data("L1", t0-16, t0+16)
bp = filter_design.bandpass(50, 250, h.sample_rate)
ns = [filter_design.notch(f, h.sample_rate)
      for f in (60, 120, 180)]
zpk = filter_design.concatenate_zpks(bp, *ns)
hf = h.filter(zpk, filtfilt=True)
lf = l.filter(zpk, filtfilt=True)
lf.shift("6.9ms"); lf *= -1

נשווה בין t0 - 0.4 לבין t0 + 0.2. שחזור: graphics/generate_gwpy_example.py.

GW150914 בהאנפורד ובליווינגסטון

בכל סדרה 131,072 דגימות בקצב 4,096 הרץ במשך 32 שניות. התאמה לאחר תיקון ההשהיה המתועדת של 6.9 מילישניות והכיוון היא ראיה משני גלאים עצמאיים; סינון והתאמה חזותית לבדם אינם מוכיחים גילוי. מקור: GWOSC, ברישיון CC BY 4.0.

התקנת Git ו-Julia

Git

הורידו והתקינו את Git מ-git-scm.com/downloads (Windows, macOS או Linux). אם אין אפשרות להתקין Git, השתמשו ב-Code → Download ZIP במאגר.

Julia ב-Windows

התקינו את Julia עם winget install julia -s msstore. לחלופין הורידו את המתקין מ-julialang.org/install.

Julia ב-macOS

התקינו את Juliaup: curl -fsSL https://install.julialang.org | sh, ואז juliaup add 1.12.

אימות

במסוף, julia +1.12 --version אמור להדפיס שורה המתחילה ב-julia version 1.12.

קבלת קבצי הקורס

קריאה לא דורשת התקנה: פותחים את הקישורים בעמוד הקורס. כדי להריץ קוד, משכפלים את המאגר — או, בלי Git, משתמשים ב-Code → Download ZIP במאגר ופותחים את הארכיון — ואז מתקינים את הסביבה המתועדת משורש המאגר.

git clone https://github.com/nshaviv/physprog.git
cd physprog
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. verify_environment.jl

שמירה על עדכניות ההעתקה

המאגר גדל במהלך הסמסטר: פתרונות, תרגילים נוספים ותיקונים מתווספים. משורש המאגר, נלקח את הגרסה העדכנית:

git pull --ff-only

אם השתמשתם ב-Download ZIP, הורידו ZIP חדש כשמתפרסמת גרסה. אם גרסה מעדכנת את הסביבה, הריצו שוב julia --project=. -e 'using Pkg; Pkg.instantiate()'.

התקנת VS Code

הורדה

הורידו את Visual Studio Code הרשמי מ-code.visualstudio.com עבור מערכת ההפעלה שלכם, והתקינו כרגיל.

פתיחת תיקיית הקורס

השתמשו ב-File → Open Folder ובחרו את תיקיית הקורס המשוכפלת (זו שמכילה את Project.toml).

הרחבת Julia ב-VS Code

  1. פתחו את תצוגת ה-Extensions (Ctrl+Shift+X או Cmd+Shift+X).
  2. חפשו Julia והתקינו את ההרחבה הרשמית של julialang.
  3. אם VS Code אינו מוצא את Julia, הגדירו את julia.executablePath לקובץ ההרצה של Julia (או בחרו Configure path).

לאחר מכן פתחו קובץ .jl והריצו אותו עם Run → Run Without Debugging; הפלט יופיע במסוף.

מחברות Jupyter ב-VS Code

  1. התקינו את הרחבת Jupyter מבית Microsoft מתצוגת ה-Extensions.
  2. פתחו קובץ .ipynb ולחצו על Select Kernel.
  3. בחרו את גרעין ה-Julia של הקורס, או את גרעין ה-Python עבור חברות פרק 0.

המחברות כבר מכילות את הפלט השמור, כך שקריאה בהן אינה דורשת התקנה; הרצה היא רשות.
