Meaning

Units

Known case

Evidence

Repair protocol

Record exact failures instead of paraphrasing them

1. Record the command or cell that was run.
2. Copy the exact error and line number.
3. Reduce the failure to the smallest reproducible step.
4. Inspect file names, values, types, signs, and units.
5. Change one thing and rerun the known test.
