Work sequence

  1. Download the template and the checker into the same folder.
  2. Save the template under your student ID, for example 123456789.jl.
  3. Complete the input commands, calculations, conditionals, and output lines in that file.
  4. Run the checker on your file.
  5. Submit only your completed file on Moodle.

Run the checker

Open a terminal in the folder containing both files and run:

julia hw2_checker.jl YOUR_ID.jl

The checker starts a fresh Julia process for each case and supplies five numbers through standard input. Your ordinary readline() calls therefore receive the test values; you do not add testing code or change your input commands. The checker does not modify your file.

It checks the six published cases and 18 invalid inputs, including Inf and NaN. A failing case shows the input, the expected result, and your program's actual output. Passing all checks is strong evidence that the main branches work; it does not prove correctness for every possible input.

Run your own program

To try your own numbers interactively, run:

julia YOUR_ID.jl

Enter one number per line, in the order listed in the assignment.

What the checker expects

  • The five input prompts exactly as printed in the assignment, one per line.
  • One result line when the projectile lands before the wall.
  • Three result lines when the calculated height is nonnegative.
  • Printed heights within 0.0001 m; state and outcome text compared exactly.
  • Invalid input stops with ArgumentError and prints no result lines.
