Friction follows impending motion

Complete recitation notebook

Choose a positive direction

Take uphill as positive. Without friction, \(T=P-mg\sin\theta\). If \(T>0\), impending motion is uphill and friction is downhill; if \(T<0\), it is the reverse.

Trace the branch

pull = 20.0      # N
mass = 5.0       # kg
angle = 20.0     # deg
tendency = pull - mass * 9.81 * sind(angle)   # N
if tendency > 0
    friction_direction = "downhill"
elseif tendency < 0
    friction_direction = "uphill"
else
    friction_direction = "none"
end
println(friction_direction)
downhill

Friction follows the tendency of motion, not the phrase "pulled up."

Checks

At \(T=0\), no friction is required. A horizontal plane requires no static friction. With zero friction, gravity accelerates downhill.
