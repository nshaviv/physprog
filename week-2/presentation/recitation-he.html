תרגול שבוע 2

החיכוך מתנגד לתנועה המסתמנת

עד 20 דקות של עבודה מונחית, ולאחריהן תמיכה בתרגיל הבית.

מחברת התרגול המלאה

0–5 דקות: נתונים וחיזוי

עבור P = 20 N, m = 5 kg ו-θ = 20°, נחשב תחילה T = P − mg sin θ. ללא חיכוך, לאיזה כיוון הגוף יתחיל לנוע?

נבחר מעלה המישור כחיובי. אם T > 0, הנטייה היא לעלות והחיכוך פונה מטה; אם T < 0, הנטייה היא לרדת והחיכוך פונה מעלה.

עוקבים אחר הענף

בקוד נשמור את הכוח בשם pull, את המסה ב־mass ואת הזווית ב־angle; הנטייה היא tendency.

pull = 20.0      # N
mass = 5.0       # kg
angle = 20.0     # deg
tendency = pull - mass * 9.81 * sind(angle)   # N
if tendency > 0
    friction_direction = "downhill"
elseif tendency < 0
    friction_direction = "uphill"
else
    friction_direction = "none"
end
println(friction_direction)
downhill

החיכוך מתנגד לנטיית התנועה, לא למילה „נמשך”.

5–14 דקות: מודל ובדיקות

החיכוך הסטטי מחזיק כאשר |T| ≤ μₛmg cos θ; אחרת החיכוך הקינטי מתנגד לנטייה. המודל מניח חיכוך קולון, מגע קשיח ומישור קבוע.

  • כאשר T = 0, אין צורך בחיכוך.
  • במישור אופקי אין צורך בחיכוך סטטי.
  • ללא חיכוך הכבידה מאיצה את הגוף במורד המישור.

14–20 דקות: מעבר לתרגיל הבית

נאמת קלט, נחשב את מסלול הקליע האנליטי ללא גרר עד לקיר, נסווג עלייה או ירידה, ונבדוק מעבר בגובה שווה. קלט לא תקין מעלה ArgumentError; הדפסה אינה אימות.
