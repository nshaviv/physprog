Safe sequence

readline() gives a String; parse(Float64, text) requests a number. A failed conversion is a useful error, not a value to guess.

Do not silently convert meaning

Converting to Int is allowed only when the value is exactly integral. A numerical conversion cannot decide an intended unit or physical domain.

Block on an incline: choose signs before code

Fixed-contact model

Take uphill positive. N = mg cos(θ); gravity along the slope is −mg sin(θ). Use radians for sin/cos, so convert θ = deg2rad(angle).

Piecewise friction

Required static friction is mg sin(θ). If it is ≤ μₛN, the block is stuck. Otherwise it slides downhill, with a = (−mg sin(θ)+μₖN)/m.

Valid regime: m,g>0, 0≤μₖ≤μₛ, 0≤θ<90°. Horizontal limit: required friction is zero. Frictionless limit: a=−g sin(θ).

Validate; then branch

mass = 2.0      # kg
angle = 30.0    # deg
μ_s = 0.60
μ_k = 0.40
g = 9.81        # m/s^2
if !(mass isa Real) || mass isa Bool || !isfinite(mass) || mass <= 0
    throw(ArgumentError("mass must be finite, positive, and non-Boolean"))
elseif !isfinite(angle) || !(0 <= angle < 90) || μ_k < 0 || μ_k > μ_s
    throw(ArgumentError("use 0 <= angle < 90 and 0 <= μ_k <= μ_s"))
end
θ = deg2rad(angle)   # rad
normal = mass * g * cos(θ)   # N
needed_static = mass * g * sin(θ)   # N
if needed_static <= μ_s * normal
    state = "stuck"
    acceleration = 0.0   # m/s^2
else
    state = "sliding"
    acceleration = (-needed_static + μ_k * normal) / mass   # m/s^2
end
println(state, ", a = ", acceleration, " m/s^2")
stuck, a = 0.0 m/s^2

Here mg sin30° = 9.81 N and μ_s N ≈ 10.19 N, so static friction holds. Change only μ_s to 0.40 and the result is sliding with negative acceleration: downhill in our declared convention. Equality belongs to the stuck branch.

is_finite_positive = isfinite(2.0) && 2.0 > 0
println(is_finite_positive)
println(!is_finite_positive || 2.0 == 2)

isfinite is true only for ordinary finite numbers and false for NaN or Inf. We combine it with a physical condition using &&, ||, and !.
