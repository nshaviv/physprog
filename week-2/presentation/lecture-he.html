גוף על מישור: קובעים סימנים לפני קוד

נבחר מעלה המישור כחיובי. N = mg cos(θ); רכיב הכבידה הוא −mg sin(θ). יש להמיר מעלות לרדיאנים לפני sin/cos.

אם mg sin(θ) ≤ μₛN הגוף תקוע. אחרת הוא מחליק, ו־a=(−mg sin(θ)+μₖN)/m.

תחום תקפות: m,g>0, ‏0≤μₖ≤μₛ, ‏0≤θ<90°. גבולות: אופקי נותן חיכוך נדרש אפס; ללא חיכוך a=−g sin(θ).

מאמתים ואז בוחרים ענף

mass = 2.0      # kg
angle = 30.0    # deg
μ_s = 0.60
μ_k = 0.40
g = 9.81        # m/s^2
if !(mass isa Real) || mass isa Bool || !isfinite(mass) || mass <= 0
    throw(ArgumentError("mass must be finite, positive, and non-Boolean"))
elseif !isfinite(angle) || !(0 <= angle < 90) || μ_k < 0 || μ_k > μ_s
    throw(ArgumentError("use 0 <= angle < 90 and 0 <= μ_k <= μ_s"))
end
θ = deg2rad(angle)   # rad
normal = mass * g * cos(θ)   # N
needed_static = mass * g * sin(θ)   # N
if needed_static <= μ_s * normal
    state = "stuck"
    acceleration = 0.0   # m/s^2
else
    state = "sliding"
    acceleration = (-needed_static + μ_k * normal) / mass   # m/s^2
end
println(state, ", a = ", acceleration, " m/s^2")
stuck, a = 0.0 m/s^2

שינוי μ_s בלבד ל־0.40 נותן sliding עם תאוצה שלילית: שלילי הוא במורד. קלט μ_k=0.8, μ_s=0.6 זורק ArgumentError—אין להמשיך עם מודל לא תקין.
